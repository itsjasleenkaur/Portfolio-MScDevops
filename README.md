# Jasleen Kaur — Portfolio

## About

The personal portfolio website of **Jasleen Kaur**, a Data Engineer based in Mumbai, India.
It's a single page covering her background, experience, skills, education, projects and
contact details.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

No frameworks, no build tools, no backend, no database.

## Project structure

```
portfolio/
├── index.html    the full page markup
├── style.css     all styling, layout and animation
├── script.js     navigation, scroll behaviour, reveals, demo form
└── README.md     this file
```

## How to run

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. That's it.

If you prefer, you can also serve the folder with any simple static file server —
but nothing needs to be installed for the site to work.

## Notes

- The contact form is a **demo only**. There is no backend, so submitting it shows a
  message saying nothing was sent. Email and LinkedIn links work normally.
- Fonts load from Google Fonts when you're online. Offline, the page falls back to
  system fonts and still looks and works fine.
